      02 / Example critique

      A critique you can inspect,
      not just accept.

      {# RELEASE: replace example-landscape.jpg independently of the hero and preview images. #}

      Critique excerpt

      “The road gives the eye an entry point, but the brightest cloud pulls attention away from the valley’s strongest rhythm. A slightly tighter crop from the right would let the ridge and mist carry the frame.”
      Noticed
      A winding road, layered ridges, low cloud and a bright horizon.
      Evidence
      The road creates a lower-right leading line; the brightest values sit at upper right.
      Limitation
      Atmospheric haze reduces detail, so depth and edge relationships may be interpreted conservatively.

      Static editorial example using a repository test photograph. It is not a live analysis or performance claim.

      05 / About the maker

      Built where photography and engineering meet.

      Moiz designed and built FRAMED as a long-running exploration of photography, computer vision, software engineering and AI research. The work begins with a simple standard: if a critique cannot show what it noticed and where it is uncertain, it should not ask for a photographer’s trust.

      View the project on GitHub ↗

      06 / Privacy

      A critique should not quietly become an identity.

      Public beta sessions are not treated as memory or continuity. Analysis metadata, response records and feedback may be retained for evaluation, security and product improvement; the current application removes the raw upload after the request completes.
